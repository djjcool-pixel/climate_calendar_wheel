# 季节回声 · Climate Calendar Wheel

一个零依赖、可直接打开的交互式气候年轮。将一年 365 天排列成圆环，探索不同日期及城市之间的近似气候对应关系。

## 在线使用 / 本地运行

项目为纯静态单页网站。下载或克隆仓库后，直接打开 `index.html` 即可；也可以部署到 GitHub Pages、Vercel 或任何静态文件服务器，无需构建命令、数据库或 API Key。

## 功能

- **气温年轮（主视图）**：展示全年逐日气温的冷暖分布。默认打开当天；鼠标悬停外圈实时预览，点击确认日期。手机可沿外圈触摸拨动，松手确认。
- **服装推荐**：根据源城市与所选日期的参考日均温、低温和高温，推荐上装、外搭、下装、鞋履；补充昼夜温差、月度湿度与降水提示。选定日期后更新，拖动预览期间保留已选日期的建议，减少连续排版开销。穿搭建议使用完整温度范围，不随比较指标或目标城市改变；参考历史气候，出门前仍需结合实时天气和个人体感。
- **手机穿搭预览**：服装推荐默认折叠，预览卡与单城市全年温度光谱统一为 180px 高；用上装、外搭、下装、鞋履四个图标与短标签速览，展开后查看完整建议。图标通过同一套 SVG 符号复用，早晚偏冷时外搭图标标签也会同步加衣。桌面默认展开，保留原生 details 与键盘展开语义。穿搭与高级功能均有短促的双向展开/收起过渡，可中途反向操作；减少动态效果时直接切换。
- **换季参考**：右上角衣架开关控制轮盘光带外缘的少量菱形与短弧；轻点提示附近可选中参考日期，拖动和光带内点击仍保持逐日精确选择。根据源城市历史日均温跨过 12°C / 24°C 的主要穿搭档位推算，要求此前一周处于原档位、此后一周处于新档位，每城最多四处；昆明、广州等城市只显示实际跨越的档位。日期表示历史气候换装时段，不是当年天气预报。可随时关闭提示，温度光带的颜色与刻度不变。
- **全年温度光谱**：位于轮盘下方、服装推荐上方，兼作唯一的直线日期滑条。支持鼠标与触屏连续拖动、点击、方向键与 Home / End；拖动预览，松手确认。详细比较统一从“高级功能”展开。
- **日期映射（默认折叠）**：同城寻找升温季与降温季气温近似的日期，或将源城市某天映射到另一城市的近似气候日期。
- **跨城对比**：起点和目标城市并列在轮盘上方，折叠高级功能后仍可选城与交换。外圈属于起点，内圈属于目标；只拨动外圈选日期，目标对应日自动更新。图例、轮盘中心、结果与目标光谱同步标出城市和归属，轻点图例可短暂突出对应光圈。服装推荐继续以起点城市和所选日期为准。
- **气候比较**：支持平均气温、平均最高 / 最低气温以及温度优先 / 综合气候两种匹配方式，并展示湿度与降水的参考对照。
- **响应式设计与动效**：手机端优化，轮盘和信息卡自适应；提供入场、切换和连线动态效果，兼容系统减少动态效果设置。

城市：东京、北京、合肥、成都、西安、广州、武汉、哈密、昆明。默认城市为成都。

## 数据说明

本项目用于**气候季节探索**，不是天气预报。气温由月度气候平年值经平滑插值转换为 365 个参考日期的估计值，**不是逐日实测数据**。部分中国城市使用邻近站点；湿度含模型估算，降水主要按所在月份的气候参考量展示。不同数据来源与统计期间不一定完全一致；跨城市匹配结果只表示指定指标下的近似相似，不能据此判断体感、日照或极端天气。

参考信息：
- [Japan Meteorological Agency — Climate Normals](https://www.data.jma.go.jp/stats/en/normal/normal.html)
- [JMA ClimatView](https://ds.data.jma.go.jp/tcc/tcc/products/climate/climatview/frame.php)
- [Climate Zone](https://www.climate-zone.com/)
- [Climates to Travel — Hami](https://www.climatestotravel.com/climate/china/hami)：哈密气温、相对湿度与降水采用该页 1991–2020 月度参考；降水保留月份说明中的小数值。
- [Climates to Travel — Kunming](https://www.climatestotravel.com/climate/china/kunming)：昆明气温、相对湿度与降水采用该页 1991–2020 月度参考。

## 开发

主要实现为单个 `index.html`（原生 HTML/CSS/JavaScript/SVG），不包含需要联网加载的前端运行时依赖。日期映射使用参考气温曲线和加权相似度搜索；同城模式限制候选日期来自相反的升温或降温趋势。

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

### 动效与性能

默认城市为**成都**，跨城比较默认目标为东京。

- 指针与连线共用一个按需运行的 `requestAnimationFrame` 循环；使用可中途接续的阻尼运动，跨年按最短圆弧移动。日期、滑块和按钮始终以最终选定值为准。
- SVG 温度刻度、指针、连线及文本节点复用；目标城市内圈首次使用时才创建。指针输入每帧合并，匹配结果按配置与日期缓存，缓存最多保留 16 组。温度、趋势与降水参考数组按城市复用，匹配循环直接读取数值，不重复拼接键值、插值或生成评分对象；原有分数与平局选择规则保持一致。
- 温度光谱使用 CSS 渐变；折叠的比较面板延后更新。静止后停止动画循环，切换到后台、轮盘离屏或系统开启“减少动态效果”时直接归位。
- 光谱滑块使用原生 range，保留连续的小数位置以直接跟手；只在日期变化时向现有帧循环提交预览，松手后更新选定日期和穿搭。48px 滑块触摸区域锁定拖动，卡片其余区域保留纵向页面滚动；取消手势会恢复已选日期，不增加动画循环或运行时依赖。
- 手机城市框仅显示中文名称，桌面辅以英文；展开时保留完整中英文原生选项，原生控件保留 16px 字号以避免 iOS 聚焦放大。
- 轮盘结果区统一按城市与季节、日期、温度排列；手机左右对齐，桌面上下对应，以相似符号和绿橙色联系两个日期，去除装饰箭头及重复指标。复用固定文本节点，不增加动画或交互监听。
- 手机端省去工具栏的“城市 / 比较指标 / 日期”可见标签，日期行占满工具栏宽度；标签仍提供读屏名称，桌面继续显示。
- 手机端收紧标题、卡片和模块间距，保留原有配色、年轮尺寸、英文小标题和卡片层级；主要控件保持 44px 高，光谱触摸区域保持 48px。
- 表盘按压时沿触点方向轻移并产生最多 5° 的倾斜，松手阻尼回正；与指针共用按需动画循环，归位后移除 3D 变换和临时合成层。开启“减少动态效果”时不倾斜。
- 指针光晕使用独立元素的合成变换，保持原有尺寸、渐变与过渡；避免通过继承的 CSS 变量逐帧影响整张 SVG。点击涟漪仅在可见期间更新位置。
- 年轮刻度首次以完整 SVG 标记批量创建；后续只在模式变化时更新几何、在城市或指标变化时更新颜色。调色结果、光谱渐变与三种圆环几何复用缓存，保留每一条原始刻度及颜色过渡。
- 抽屉初始化、视窗调整与减少动态效果的直接切换跳过尺寸读取；用户操作仍使用原来的测量与双向动画。清理未使用与确定被覆盖的样式，维持单文件、无构建依赖。
- 轮盘采用静态多层阴影与轮缘高光；只更新发生变化的变换和指针几何，按压回正时不重复写入静止的 SVG。服装推荐使用本地轻量规则和缓存的气温曲线，复用固定文本节点，不新增 API 请求、定时器或动画循环。
- 换季日期按城市缓存，最多复用四组固定 SVG 标记；轮盘可见且靠近提示时只播放一次短促回应，离屏、切到后台或系统减少动态效果时停止回应动画。光带和标记的绘制区域相互独立。轮盘中心按穿搭提示、主日期与温度、相似日分层排版，保持原有绿橙配色。
- 抽屉只在激活时测量自然高度，使用浏览器动画完成 300ms 展开 / 250ms 收起及内容淡入淡出；反向点击从当前高度接续。结束即释放动画，关闭内容即时退出键盘导航；视窗调整、后台与减少动态效果会直接归位，不增加持续帧循环或外部依赖。
- 主要控件统一 44px 高，使用 SVG 导航图标；分段按钮的选中底色平滑滑动。触屏上沿外圈拨动，中心区域可正常滚动页面。

实测结果与限制见 [2026-10-24 性能对照](docs/performance-2026-10-24.md)。本次轮盘拖动的主线程耗时明显下降，首屏收益较小，未达到整站加载与流畅度同时翻倍。
